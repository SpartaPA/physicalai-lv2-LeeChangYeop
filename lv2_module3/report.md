# LV2 Module 3 분석 보고서

## 1. ROS 2 토픽 구성

| 구분 | 토픽 이름 | 메시지 타입 | 용도 |
|---|---|---|---|
| Raw Image | `/camera/camera/color/image_raw` | `sensor_msgs/msg/Image` | 원본 RGB 영상 |
| Mask | `/target/debug_mask` | `sensor_msgs/msg/Image` | HSV 조건으로 분리된 영역 |
| 검출 결과 | `/target` | `geometry_msgs/msg/PointStamped` | 목표물 위치 및 면적 비율 |
| Debug Image | `/target/debug_image` | `sensor_msgs/msg/Image` | 검출 바운더리가 표시된 영상 |

`/target`의 `x(ex)`는 화면 중심 기준 좌우 위치, `y(ey)`는 화면 중심 기준 상하 위치, `z(area)`는 화면 전체 대비 목표물 윤곽선 면적 비율이다. `ex`는 음수일 때 왼쪽, 양수일 때 오른쪽이며, `ey`는 음수일 때 위쪽, 양수일 때 아래쪽이다. `(0, 0, 0)`은 목표물 미검출을 나타낸다.

## 2. 실험 가설 및 통제 조건

### 2.1. 통제 조건

- 카메라: Intel RealSense D435
- 입력 해상도: 640 × 480
- A/B 실험에서 동일한 카메라 위치와 목표물 장면 사용
- 실험마다 변경 파라미터 하나만 변경하고 나머지 설정값은 고정
- Raw Image, Mask, 검출 결과 및 로그 기록

실험별 측정 시간과 프레임 수가 완전히 같지 않으므로 검출률뿐 아니라 Mask 변화와 오검출 여부도 함께 비교했다.

### 2.2. 실험 가설

| 실험 | 독립 변수 | 종속 변수 | 가설 |
|---|---|---|---|
| 실험 1 | HSV 범위의 S 하한 | Mask 영역, 검출 면적, 위치 변동, 오검출 | S 하한을 낮추면 낮은 채도의 픽셀도 포함되어 검출 영역이 커지거나 배경 오검출이 발생할 수 있다. |
| 실험 2 | `min_fill_ratio` | 후보 필터 통과 여부 및 최종 검출 | 채움률 기준을 높이면 일부 후보가 탈락하며, 기준이 지나치게 높으면 실제 목표물도 검출되지 않을 수 있다. |

## 3. 실험 1 — HSV 설정 변경

### 3.1. A/B 설정

| 항목 | A 설정 | B 설정 |
|---|---|---|
| HSV Lower | `[98, 190, 25]` | `[98, 20, 25]` |
| HSV Upper | `[118, 255, 230]` | `[118, 255, 230]` |

공통 설정: `blur_ksize: 5`, `morph_kernel: 5`(Open 1회, Close 2회), `min_area_px: 300`, `bbox_style: rotated`, `max_distance_m: 1.5`, `min_fill_ratio: 0.5`.

`perception/config/perception.yaml`의 HSV 설정을 사용했으며, B 설정에서는 S 하한만 190에서 20으로 변경했다.

### 3.2. A/B 결과 비교

| 비교 항목 | A 설정 | B 설정 |
|---|---:|---:|
| 대표 ex | -0.242 | -0.247 |
| 대표 ey | 0.304 | 0.290 |
| 대표 area | 0.0269 | 0.0443 |
| 전체 프레임 | 186 | 199 |
| 검출 프레임 | 160 | 168 |
| 기록된 검출률 | 86.0% | 84.4% |
| 위치 변동 | ex: -0.241~-0.244 | ex: -0.206~-0.271 |
| 배경 오검출 | 기록상 없음 | 발생 |

A 설정에서는 `area`가 약 0.0267~0.0270으로 비교적 일정했다. B 설정에서는 `area`가 약 0.041~0.047로 커졌고, `ey`도 약 0.275~0.350 범위로 변동했다. B 설정에서 화면 상단의 비목표물 영역이 `ex ≈ -0.021`, `ey ≈ -0.538`, `area ≈ 0.0018`로 검출된 사례도 기록되었다.

S 하한을 낮추자 더 많은 픽셀이 HSV 범위에 포함되면서 검출 면적과 위치 변동이 증가했고, 배경 오검출도 발생했다. 기록된 검출률은 A 86.0%, B 84.4%지만 측정 시간과 프레임 수가 달라 검출률만으로 성능 차이를 확정할 수는 없다.

### 3.3. 코드 근거 및 최종 선택값

HSV 설정은 `perception/config/perception.yaml`에서 관리한다. HSV 범위는 Mask에 포함되는 픽셀을 결정하므로 S 하한을 낮추면 낮은 채도의 픽셀도 포함될 수 있다.

**최종 선택값:** Lower `[98, 190, 25]`, Upper `[118, 255, 230]`

**선정 근거:** A 설정에서 검출 면적과 위치가 비교적 안정적이었고, B 설정에서 발생한 배경 오검출이 기록되지 않았다.

## 4. 실험 2 — 후보 영역 필터 설정 변경

### 4.1. A/B 설정

HSV 범위를 고정하고 `detector.min_fill_ratio`만 변경했다.

| 항목 | A 설정 | B 설정 |
|---|---:|---:|
| `min_fill_ratio` | 0.5 | 0.95 |
| HSV Lower | `[98, 190, 25]` | `[98, 190, 25]` |
| HSV Upper | `[118, 255, 230]` | `[118, 255, 230]` |
| `min_area_px` | 300 | 300 |
| `max_distance_m` | 1.5 | 1.5 |

실험 기록에서는 채움률을 `contour_area / rotated_bbox_area`로 정의했다.

### 4.2. A/B 결과 비교

| 비교 항목 | A 설정 | B 설정 |
|---|---:|---:|
| Mask 내 목표물 영역 | 존재 | 존재 |
| 대표 ex | -0.242 | 0.000 |
| 대표 ey | 0.304 | 0.000 |
| 대표 area | 0.0269 | 0.0000 |
| 전체 프레임 | 186 | 36 |
| 검출 프레임 | 160 | 0 |
| 기록된 검출률 | 86.0% | 0% |
| 최종 검출 | 정상 검출 | 미검출 |

A 설정에서는 목표물 후보가 필터를 통과해 검출되었다. B 설정에서는 Mask에 목표물 영역이 남아 있었지만 최종 검출 결과가 출력되지 않았다. 이는 `min_fill_ratio`를 0.95로 높였을 때 후보가 필터에서 탈락했음을 보여준다. 후보별 실제 채움률 수치는 기록되지 않아 정확한 탈락 임계값을 수치로 제시할 수는 없다.

### 4.3. 코드 근거 및 최종 선택값

설정 파일의 관련 항목은 다음과 같다.

```yaml
detector:
  min_area_px: 300.0
  min_fill_ratio: 0.5
  max_distance_m: 1.5
```

`min_area_px`는 후보 윤곽선의 최소 면적, `min_fill_ratio`는 윤곽선 면적과 회전 바운딩 박스 면적 비율의 최소 기준, `max_distance_m`는 깊이 정보를 이용할 때 적용하는 최대 거리 제한이다.

**최종 선택값:** `min_fill_ratio: 0.5`

**선정 근거:** A 설정에서는 목표물이 검출되었으나 B 설정에서는 검출률 0%로 기록되었다. 다만 특정 목표물과 배경에서 진행한 결과이므로 다른 형태의 목표물에도 0.5가 최적이라고 단정할 수는 없다.

## 5. 목표물이 없는 입력 테스트

목표물을 치운 장면에서 A 설정을 사용했다. HSV Lower `[98, 190, 25]`, Upper `[118, 255, 230]`, `min_area_px: 300`, `min_fill_ratio: 0.5`, `max_distance_m: 1.5`를 적용했다.

| 항목 | 결과 |
|---|---:|
| 전체 프레임 | 112 |
| 검출 프레임 | 0 |
| 기록된 검출률 | 0% |
| ex | 0.000 |
| ey | 0.000 |
| area | 0.0000 |

Mask 전체가 검은색으로 나타났고 검출 바운더리도 표시되지 않았다. 약 25초 동안 0이 아닌 검출값은 수신되지 않았으며, `/target`은 `(0, 0, 0)`을 유지했다. 해당 장면에서는 배경 오검출이 관찰되지 않았다.

## 6. 최종 선택값

| 설정 항목 | 최종 선택값 | 선정 근거 |
|---|---|---|
| HSV Lower | `[98, 190, 25]` | 검출 면적과 위치가 비교적 안정적이고 배경 오검출이 기록되지 않음 |
| HSV Upper | `[118, 255, 230]` | 실험에서 고정해 사용한 상한 |
| `min_area_px` | `300.0` | 실험에서 고정해 사용한 기준 |
| `min_fill_ratio` | `0.5` | 목표물 검출 성공, 0.95에서는 미검출 |
| `max_distance_m` | `1.5` | 실험에서 고정해 사용한 거리 제한 |
| `blur_ksize` | `5` | 실험에서 고정해 사용한 값 |
| `morph_kernel` | `5` | 실험에서 고정해 사용한 값 |
| `bbox_style` | `rotated` | 실험에서 고정해 사용한 방식 |

## 7. 결론

HSV S 하한을 190에서 20으로 낮추자 검출 면적과 위치 변동이 증가하고 배경 오검출이 발생했다. `min_fill_ratio`를 0.5에서 0.95로 높였을 때는 Mask에 목표물 영역이 남아 있었지만 최종 검출이 이루어지지 않았다. 목표물이 없는 입력에서는 `/target`이 `(0, 0, 0)`을 유지했고 해당 장면에서 오검출은 관찰되지 않았다.

실험 결과를 바탕으로 HSV Lower `[98, 190, 25]`, Upper `[118, 255, 230]`, `min_fill_ratio: 0.5`를 최종 선택했다.
